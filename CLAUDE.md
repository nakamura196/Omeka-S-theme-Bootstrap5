# Notes for AI coding agents

- Write commit messages, pull requests and issues in English, as described in [CONTRIBUTING.md](CONTRIBUTING.md). Follow its pull request steps too.
- Keep changes to templates copied from Omeka S core small and close to the core template.
- When user-visible text changes, update `language/ja.po` and recompile `language/ja.mo`.
- Add an entry to `CHANGELOG.md` under "Unreleased".
